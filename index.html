AI Setup Guide

A friendly step-by-step guide to set up OpenRouter and LibreChat for your AI adventures!

Hey there! I've made this guide just for you to help set up your own AI assistant. Follow these steps and you'll be chatting with AI in no time!

Take your time with each step, and don't hesitate to ask if you get stuck!

Phase 1

Get Your OpenRouter API Key

First, we need to get an API key from OpenRouter. This key will allow LibreChat to access AI models.

  1. Go to https://openrouter.ai
  2. Click "Sign Up" and create an account using your email.
  3. Once logged in, click on your profile picture or name in the top right corner and select "Keys".
  4. Click the "Create Key" button.
  5. Give it a simple name (e.g., "My LibreChat Key") and click "Create".

IMPORTANT

Copy the long code that appears (your API Key). Save it somewhere safe, like a text file on your computer. You will need it soon.

Add some credit: You'll need to add at least £10 to your OpenRouter account to use the AI models.

Phase 2

Create Your LibreChat Account

Now let's set up your LibreChat account where you'll actually chat with the AI.

  1. Open a new browser tab and go to https://chat.ourbookings.ovh
  2. On the LibreChat login page, click "Sign up".
  3. Fill in the form with a Username, Email, and Password.
  4. Click the "Sign Up" button. You are now registered and logged in.
Phase 3

Enter Your OpenRouter API Key

Now we need to connect your OpenRouter account to LibreChat.

  1. In LibreChat, look for the settings menu. This is usually a gear/cog icon (⚙) in the bottom left corner of the chat screen or next to your username.
  2. Click it to open Settings.
  3. Find and select the tab or section labeled "API Keys".
  4. Look for "OpenRouter" in the list of services.
  5. Paste the API Key you copied from OpenRouter into the field next to it.
  6. Click "Save" or "Apply".
Phase 4

Create Your First Agent

Now let's create your first AI agent (a specialized AI assistant).

  1. In LibreChat, find the menu for "Agents". This might be in the main left sidebar or under a separate section in the settings.
  2. Click "Create New Agent" or a similar button.
  3. Give your agent a Name (e.g., "Essay Writer").
  4. For the Model:
    • In the "Model" dropdown, select deepseek/deepseek-chat-v4. I recommend this because it has a very high context window, meaning it can remember and use much longer instructions.
    • Set the temperature to 0.3 and set the reasoning level to medium or high.
  5. Enable File Search:
    • Look for a checkbox, toggle, or option labeled "File Search" or "Enable File Upload".
    • Enable/check this option. This allows your agent to read PDFs and other documents you upload.
  6. For the Agent Instructions/Prompt:
    • I have written the detailed instructions for your agent in a document: Agent Instructions Document.
    • Use the prompt in this Google doc (use Claude Sonnet as the model) and don't forget to attach your own essay and use the output as the agent instruction for your agent.
  7. Click "Save Agent".

Phase 5

Upload a PDF and Start Chatting

You're almost done! Now let's actually use your AI agent.

  1. Go back to the main chat screen.
  2. In the dropdown menu where you select your Agent or model, choose the Agent you just created (e.g., "Essay writer").
  3. Look for the upload button (usually a paperclip icon or "Upload" button).
  4. Select a PDF file from your computer to upload.
  5. Start chatting with your AI agent! You can ask it questions about the PDF or give it tasks related to your essay.

Congratulations!

You've successfully set up your own AI assistant! Now you can create more agents for different purposes, try different models, and explore all the features of LibreChat.
